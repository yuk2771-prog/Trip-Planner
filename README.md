# Trip Planner

브라우저에서 바로 쓰는 여행 플래너입니다. 설치나 서버 없이 `index.html` 파일 하나로 동작합니다.

## 기능

- **일정**: 도시와 박 수만 넣으면 날짜가 자동 계산되고, 도시 사이의 이동(버스·항공 등)이 한 줄로 이어져 보임
- **예산**: 체류비·이동비·고정비 합계와 나라별 체류비
- **가계부**: 금액과 분류만 누르면 바로 기록, 남은 예산 표시
- **준비**: 미리 예약할 것, 할 일, 짐 체크리스트
- **정보**: 나라별 긴급번호·통화·치안, 메모
- 고치고 싶은 항목은 **누르면 편집 창**이 열림 (저장 / 취소 / 삭제)
- 여러 여행 저장, 복제, 삭제 (위쪽 여행 이름을 누르기)
- 환율 자동 불러오기 (open.er-api.com)
- 화면 테마: 파스텔 5종, 다크 모드, 시스템 설정 따라가기 (설정, 기기마다 따로 기억)

## GitHub Pages로 올리기

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일(`index.html`, `README.md`, `.gitignore`)을 올립니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Source**를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 두고 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 열립니다.

## 데이터는 어디에 저장되나요?

- 여행 데이터는 **저장소가 아니라 각 기기의 브라우저**에 저장됩니다. 그래서 저장소를 공개해도 가계부나 메모는 올라가지 않습니다.
- 맥북과 휴대폰은 각자 따로 저장합니다. 하단에서 기기 이름을 정해 두면 어느 기기의 데이터인지 구분하기 쉽습니다.
- 같은 기기라도 `index.html`을 파일로 열 때와 GitHub Pages 주소로 열 때는 저장 공간이 다릅니다.
- 브라우저 데이터를 지우거나 시크릿 모드로 열면 데이터가 보이지 않습니다.

## 내보내기

위쪽의 **내보내기** 버튼을 누르면 두 가지가 있습니다.

| 종류 | 버튼 | 하는 일 |
|---|---|---|
| 문서 | PDF로 저장 | 정리된 일정표를 인쇄 창으로 엶. 인쇄 창에서 "PDF로 저장"을 고르세요 (iPhone은 공유 버튼 → 파일에 저장) |
| 문서 | HTML 파일로 저장 | 아무 브라우저에서나 열리는 읽기 전용 일정표 파일 |
| 백업 | 지금 여행 백업 / 모든 여행 백업 | 이 앱으로 다시 불러오는 데이터 파일(.json). 다른 기기로 옮기거나 보관할 때 |

문서에 넣을 항목(일정, 예산, 준비물, 나라 정보, 메모, 가계부)은 고를 수 있습니다. 가계부는 기본으로 빠져 있습니다.

다른 기기로 옮기기: 맥북에서 "지금 여행 백업" → 파일을 휴대폰으로 전송 → 휴대폰에서 "백업 파일 가져오기". 이미 있는 여행이면 덮어쓸지, 사본으로 추가할지 고릅니다.

## 주의

내보낸 `.json` 파일과 `trips/` 폴더는 `.gitignore`에 들어 있어 저장소에 올라가지 않습니다.
가계부와 메모가 들어 있으니, 공개 저장소에는 올리지 마세요.
