# Trip Planner

브라우저에서 바로 쓰는 여행 플래너입니다. 설치나 서버 없이 `index.html` 파일 하나로 동작합니다.

## 기능

- 도시 일정: 박 수만 넣으면 날짜, 국가별 체류비, 총 예산이 자동 계산됨
- 이동, 예산, 가계부, 예약, 준비 체크리스트, 짐 리스트, 국가 정보, 메모
- 보기 모드 / 편집 모드 (편집 후 저장 또는 취소)
- 여러 여행 저장, 복제, 삭제
- 환율 자동 불러오기 (open.er-api.com)

## GitHub Pages로 올리기

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일(`index.html`, `README.md`, `.gitignore`)을 올립니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Source**를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 두고 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 열립니다.

## 데이터는 어디에 저장되나요?

- 여행 데이터는 **저장소가 아니라 각 기기의 브라우저**에 저장됩니다. 그래서 저장소를 공개해도 가계부나 메모는 올라가지 않습니다.
- 맥북과 휴대폰은 각자 따로 저장합니다. 하단에서 기기 이름을 정해 두면 어느 기기의 데이터인지 구분하기 쉽습니다.
- 같은 기기라도 `index.html`을 파일로 열 때와 GitHub Pages 주소로 열 때는 저장 공간이 다릅니다.
- 브라우저 데이터를 지우거나 시크릿 모드로 열면 데이터가 보이지 않습니다.

## 기기 간 이동 / 백업

| 버튼 | 하는 일 |
|---|---|
| 이 여행 내보내기 | 지금 보고 있는 여행 하나를 `여행이름_날짜_기기.json` 파일로 저장 |
| 전체 백업 | 이 기기의 모든 여행을 파일 하나로 저장 |
| 가져오기 | 여행 파일이나 전체 백업 파일을 불러옴 (여러 개 동시 선택 가능). 이미 있는 여행이면 덮어쓸지, 사본으로 추가할지 선택 |

예: 맥북에서 "이 여행 내보내기" → 파일을 휴대폰으로 전송 → 휴대폰에서 "가져오기".

## 주의

내보낸 `.json` 파일과 `trips/` 폴더는 `.gitignore`에 들어 있어 저장소에 올라가지 않습니다.
가계부와 메모가 들어 있으니, 공개 저장소에는 올리지 마세요.
